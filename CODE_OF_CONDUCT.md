# Code of conduct

PcyBox GoLive adopts the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be respectful, assume good intent, welcome newcomers, and keep discussions focused on the work. Harassment, discrimination and personal attacks are not tolerated in any project space.

Report unacceptable behaviour privately to the maintainers through a GitHub security advisory or a direct message to a maintainer. Reports are handled confidentially.
